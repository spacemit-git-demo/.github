## Who We Are

SpacemiT is a RISC-V AI CPU company focused on building specialized processing cores for intelligent edge and server-class AI workloads.
We provide chip-level software foundation, AI runtime, hardware specifications and application examples to help partners build production-ready intelligent products.

进迭时空是一家专注 RISC-V AI CPU 的处理器公司，面向智能边缘与服务器级 AI 负载，提供芯片软件底座、AI 运行时、硬件规范与应用示例，帮助合作伙伴构建可量产的智能产品。

## Target Markets

- **Agent Computer** — On-device LLM reasoning, task planning, tool use and local intelligent agents.
- **Robot Computer** — On-board perception, decision-making, motion control and embodied intelligence.
